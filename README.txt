G6 Simulator PWA

Fristående demo/simulering av BLH Nobel G6 PM. Ingen riktig hårdvara eller I/O används.

Ladda upp index.html, manifest.json, sw.js och icon.svg till roten på GitHub och publicera via GitHub Pages (main / root).

Källa för meny- och funktionsstruktur: BLH Nobel G6 Multi Channel Weighing Instrument Technical Manual, program version 2.5.x:
https://docs.blhnobel.com/?id=17805

Detta är en fristående simulering och inte officiell BLH Nobel-programvara.
